# Creator profile

Save as `creator-profile.md` in the creator's content root (for example `~/Desktop/Claude-Cowork/personal_brand/creator-profile.md`).
The skill looks for it in the video folder and each parent folder, and reads it before asking anything.
Keep it short; update it when the creator corrects something twice.

```markdown
# Creator profile

- Name / handle: <name> / @<handle>
- Language: Thai, with English tech terms kept in English
- Platforms: TikTok, Instagram Reels, YouTube Shorts (all)
- Default style profile: tech-dark-accent
- Default accent (no brand in story): #F6821F
- Fonts: Kanit + JetBrains Mono
- Caption style: white, 12 px black outline, English keywords in accent, 2-4 words per chunk
- CTA style: a question that invites comments, at the end, then stop
- Name tag: show @<handle> lower-left the first time I speak (yes/no)

## Spelling list (fix these in transcripts and captions)

- Cloudflare, Wrangler, Workers, D1, R2, KV, Durable Object
- Claude, Claude Code, OpenAI, AWS, VPS, Instance
- Backend, Frontend, Deploy, Maintenance, Freelance

## Keep-together terms (never split in a caption chunk)

- โปรเจกต์, ค่อนข้าง, Cloudflare Wrangler, D1 Database, R2 Bucket, Read Only, Durable Object

## Preferences learned from feedback

- PiP must show the whole head, including the hair (2026-10-02).
- Music should be audible under fast talking: mix with --gap-db 17 --duck-db 7.
```
